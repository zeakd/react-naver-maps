GroundOverlay

GroundOverlay 컴포넌트는 이미지를 지도 위에 오버레이합니다. url 또는 bounds가 변경되면 인스턴스가 재생성됩니다.

사용법

import { GroundOverlay } from 'react-naver-maps';

<GroundOverlay
  url="https://example.com/overlay.png"
  bounds={{ south: 37.5, west: 126.9, north: 37.6, east: 127.0 }}
  opacity={0.7}
/>;

Props

이름타입필수기본값설명
urlstring✓--
boundsnaver.maps.LatLngBounds | naver.maps.LatLngBoundsLiteral✓--
opacitynumber | undefined---
clickableboolean | undefined---
crossOriginstring | undefined--이미지 요청의 CORS 모드. SDK 패턴: controlled (`_crossOrigin_changed` KVO 핸들러). 일반적인 값은 `"anonymous"`, `"use-credentials"`.
