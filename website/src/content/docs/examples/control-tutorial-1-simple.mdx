## 설명

`zoomControl`, `scaleControl`, `mapDataControl` prop 이 컨트롤의 표시 여부입니다. state 로 바꾸면 컨트롤이 추가되고 제거됩니다. `minZoom` 도 같은 방식의 prop 입니다.

`logoControl={false}` 는 SDK 가 거부해서 로고는 항상 보입니다. 공식 예제에서도 마찬가지입니다. 위치만 `logoControlOptions` 로 바꿀 수 있습니다.
