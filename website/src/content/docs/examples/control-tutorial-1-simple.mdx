## 설명

`zoomControl`, `scaleControl`, `mapDataControl` prop으로 컨트롤의 표시 여부를 설정합니다. state를 변경하면 컨트롤이 추가되거나 제거됩니다. `minZoom`도 같은 방식으로 설정합니다.

SDK가 `logoControl={false}`를 거부하므로 로고는 항상 표시됩니다. 공식 예제에서도 마찬가지입니다. 위치는 `logoControlOptions`로 변경할 수 있습니다.
