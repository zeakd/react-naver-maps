## 설명

`<Layer name mapTypes />` 가 `new naver.maps.Layer(name, MapTypeRegistry)` 입니다. 레이어 유형 레지스트리(`label`)는 `useMemo` 로 한 번만 만듭니다.

켜고 끄는 것은 `ref.setMap` 이 아니라 마운트로 합니다. 자세한 내용은 [Layer](/api-references/layer) 를 보세요.
