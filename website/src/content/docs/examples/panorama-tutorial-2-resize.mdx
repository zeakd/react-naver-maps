## 설명

SDK 는 Container 가 바뀌어도 거리뷰 크기를 따라가지 않으므로 `Container` 의 크기와 `Panorama` 의 `size` prop 을 같은 state 로 함께 바꿉니다. 500ms 보간은 `useAnimatedSize` 가 `requestAnimationFrame` 마다 state 를 갱신해 만듭니다.
