## 설명

SDK 는 Container 가 바뀌어도 거리뷰 크기를 따라가지 않으므로 `Container` 의 크기와 `Panorama` 의 `size` prop 을 같은 state 로 함께 바꿉니다. jQuery `animate` 에 해당하는 500ms 보간은 `requestAnimationFrame` 으로 state 를 갱신합니다.
