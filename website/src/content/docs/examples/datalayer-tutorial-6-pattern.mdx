## 설명

스타일의 `fillColor` 에 `url(#패턴id)` 를 주면 SVG `<pattern>` 으로 채웁니다. 패턴은 페이지에 숨겨 둔 `<svg><defs>` 에 React 로 그립니다. 공식 예제의 패턴 18개는 문서에 적힌 대용량 SVG 라서 옮기지 않고, 같은 방식으로 직접 만든 6개를 씁니다. 지역에 패턴을 고르는 것은 공식의 무작위 대신 지역 이름으로 정해 렌더마다 바뀌지 않게 했습니다.
