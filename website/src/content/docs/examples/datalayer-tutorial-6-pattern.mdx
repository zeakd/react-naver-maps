## 설명

스타일의 `fillColor` 에 `url(#패턴id)` 를 주면 SVG `<pattern>` 으로 채웁니다. 패턴은 페이지에 숨겨 둔 `<svg><defs>` 에 React 로 그리고, `style` 함수는 컴포넌트 밖에 두어 참조가 바뀌지 않게 합니다.
