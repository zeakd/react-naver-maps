## 설명

경로 JSON 의 구간(step)마다 `"경도,위도 ..."` 문자열을 `{ lat, lng }` 배열로 바꿉니다. 단일은 모든 구간을 이어 붙인 `Polyline` 하나, 멀티는 구간마다 `Polyline` 하나입니다.
