실시간 교통정보 레이어를 켜고 끄며, 자동 새로고침을 정하는 예제입니다.

<Example of={TrafficTutorial3Example} />

## 설명

`<TrafficLayer interval autoRefresh />` 입니다. `interval` 은 새로고침 주기(ms, 최소 5분)이고 생성 때만 적용됩니다. `autoRefresh` 는 SDK 의 `startAutoRefresh()`, `endAutoRefresh()` 를 대신합니다.

레이어 켜짐과 자동 새로고침 체크는 모두 React state 입니다.
