## 설명

도구 막대의 위치와 모양은 `drawingControlOptions`, 보일 아이콘은 `drawingControl`, 도형 기본 스타일은 `rectangleOptions` 등의 prop 입니다. 라디오와 체크박스는 React state로 두고 prop으로 넘깁니다.

편집을 켠 도형(`editable`)은 SDK가 영역을 제자리에서 고치므로 `defaultBounds`로 둡니다. 편집한 영역이 필요하면 `ref`로 받은 인스턴스에서 읽습니다.
