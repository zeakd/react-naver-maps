## 설명

공식 예제의 `setOptions` 호출은 모두 prop 입니다. 위치와 모양은 `drawingControlOptions`, 보일 아이콘은 `drawingControl`, 도형 기본 스타일은 `rectangleOptions` 등입니다. 라디오와 체크박스는 React state 로 두고 prop 으로 넘깁니다.

공식 예제의 `rect2.setEditable(true)` 는 도형의 `editable` prop 입니다. 편집한 결과는 SDK 가 도형의 영역을 제자리에서 고치므로 `defaultBounds` 로 두고 ref 로 읽습니다.
