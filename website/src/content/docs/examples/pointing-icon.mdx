## 설명

`Polyline` 의 `startIcon`/`endIcon` 에 `navermaps.PointingIcon.OPEN_ARROW` 같은 상수를 주고, `startIconSize`/`endIconSize`(픽셀)로 크기를 고정합니다. 크기를 안 주면 `strokeWeight` 에 따라 커집니다.
