## 설명

`<LabelLayer />`는 벡터 지도에 얹는 레이어라서 `NaverMap`의 `mapTypes`에 `NaverStyleMapTypeOptions.getVectorMap()`을 `normal`로 등록합니다. 자세한 내용은 [LabelLayer](/react-naver-maps/api-references/label-layer/)를 보세요.
