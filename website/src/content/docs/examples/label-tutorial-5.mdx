<Example of={LabelTutorial5Example} />

## 설명

`<LabelLayer />` 는 벡터 지도에 얹는 레이어라서 `NaverMap` 의 `mapTypes` 에 `NaverStyleMapTypeOptions.getVectorMap()` 을 `normal` 로 등록합니다. 레지스트리는 `useMemo` 로 한 번만 만듭니다.

켜고 끄는 것은 마운트로 합니다. 자세한 내용은 [LabelLayer](/api-references/label-layer) 를 보세요.
