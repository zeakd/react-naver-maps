## 설명

`InfoWindow` 의 `maxWidth`, `backgroundColor`, `borderColor`, `borderWidth`, `anchorSize`, `anchorSkew`, `anchorColor`, `pixelOffset` 을 그대로 prop 으로 줍니다. 마커는 `ref` 로 state 에 담아 `anchor` 로 넘기고, 열고 닫기는 `open` state 입니다. 처음에는 닫혀 있습니다.
