GeoJSON geometry 안의 스타일 값(`mantle_properties`)을 `autoStyle`로 적용합니다.

<Example of={MantleTutorial5PropertiesExample} />

## 설명

`GeoJson`의 `autoStyle`을 켜면 SDK가 geometry 의 `mantle_properties`를 스타일로 씁니다. 클릭한 feature 만 다른 색으로 바꾸려고 `style` 함수가 원본의 `mantle_properties`를 읽어 돌려줍니다(`feature.getGeometries()[0].getRaw()`, 타입에 없어 단언을 씁니다).
