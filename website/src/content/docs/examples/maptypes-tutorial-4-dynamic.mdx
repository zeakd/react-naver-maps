## 설명

지도 유형 컨트롤(`mapTypeControlOptions`)로 투영법이 다른 두 유형을 전환합니다.

타일 크기는 선언적 prop이 없어서 지도 유형 인스턴스의 `getMapTypeOptions()`, `setMapTypeOptions()`로 바꿉니다.
