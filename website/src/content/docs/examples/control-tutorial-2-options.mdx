## 설명

`zoomControlOptions` 의 `style`, `position` 에 `navermaps.ZoomControlStyle.SMALL`, `navermaps.Position.TOP_RIGHT` 를 줍니다. 상수는 `useNavermaps()` 가 주는 `navermaps` 에서 받습니다.
