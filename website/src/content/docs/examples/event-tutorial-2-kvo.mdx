## 설명

SDK 의 `zoom_changed`, `bounds_changed` 같은 KVO 이벤트는 `onZoomChanged`, `onBoundsChanged` 처럼 `on*Changed` prop 입니다. 값이 인자로 옵니다.

`getCenterPoint()` 처럼 SDK 메서드가 필요하면 `ref` 로 받은 지도에 부릅니다. `padding` 도 지도 옵션 prop 입니다.

공식 예제가 `contentEl.appendTo(map.getElement())` 로 붙이던 패널은 `Container` 안의 일반 요소입니다.
