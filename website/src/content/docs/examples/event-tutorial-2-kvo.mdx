## 설명

SDK의 `zoom_changed`, `bounds_changed` 같은 KVO 이벤트는 `onZoomChanged`, `onBoundsChanged` 처럼 `on*Changed` prop으로 받습니다. 변경된 값은 인자로 전달됩니다.

`getCenterPoint()` 같은 SDK 메서드는 `ref`로 받은 지도에서 호출합니다. `padding` 도 지도 옵션 prop으로 사용할 수 있습니다.
