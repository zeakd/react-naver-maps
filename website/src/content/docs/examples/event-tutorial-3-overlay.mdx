<Example of={EventTutorial3OverlayExample} />

## 설명

오버레이 이벤트는 각 컴포넌트의 `on*` prop 입니다(`<Marker onClick>`, `<Polyline onMousedown onMouseup>`, `<Polygon onMouseover onMouseout>`, `<Rectangle onMousemove>`, `<Circle onDblclick>`). 이벤트가 바꾸는 선 굵기, 투명도, 반지름은 React state 이고 해당 prop 으로 넘깁니다. 마우스 커서는 `NaverMap` 의 `cursor` prop 입니다.

정보 창은 열린 대상을 state 로 갖고 `<InfoWindow open anchor content />` 로 그립니다. 마커 `anchor` 는 `ref` 로 받은 Marker 입니다.

`Ellipse` 의 `touchstart`, `touchend` 는 `on*` prop 이 없어 `useListener` 를 씁니다.
