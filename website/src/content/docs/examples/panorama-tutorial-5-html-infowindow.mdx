## 설명

`Panorama` 의 자식으로 `Marker` 와 `InfoWindow` 를 둡니다. `open` 을 state 로 두고 마커의 `onClick` 에서 토글하며, `anchor` 에 마커 좌표를 줍니다. 마커가 거리뷰 위치에서 멀면(이 예제는 약 1km) SDK 가 그리지 않으므로 `onInit` 에서 마커 방향으로 `pov` 를 돌려도 마커가 보이지 않을 수 있습니다.
