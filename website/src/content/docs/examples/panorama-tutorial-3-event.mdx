## 설명

`onPanoChanged`, `onPovChanged`, `onPanoStatus` prop 으로 이벤트를 받고, 값은 `ref` 로 받은 인스턴스에서 읽습니다(`getLocation()`, `getPov()`, `getZoom()` 등). 확대·축소 버튼은 같은 인스턴스의 `zoomIn()`, `zoomOut()` 입니다.
