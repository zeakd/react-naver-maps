## 설명

`HeatMap` 의 `colorMap` 에 `navermaps.visualization.SpectrumStyle` 값(공식 예제는 `HOT`)을 주고, `colorMapInReverse` 로 색을 거꾸로 칠합니다. 공식 예제는 `HOT` 하나지만 여기서는 선택 상자와 체크박스로 다른 스펙트럼도 볼 수 있게 했습니다.
