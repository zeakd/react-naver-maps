## 설명

마커 위치를 state 로 두고 `NaverMap` 의 `onClick` 에서 `e.coord` 로 바꿉니다(`marker.setPosition` 을 부르지 않습니다). 클릭 좌표는 `e.coord.y`(위도), `e.coord.x`(경도) 입니다.
