## 설명

마우스를 올리면 선 색을 바꾸는 부분은 `onMouseover`/`onMouseout` 이 state 를 바꾸고, `strokeColor`·`strokeOpacity` 가 그 state 를 따르게 합니다(`polygon.setOptions` 를 부르지 않습니다). 도형 이벤트를 받으려면 `clickable` 이 필요한데, 포인터 이벤트 prop 이 있으면 자동으로 켜집니다.
