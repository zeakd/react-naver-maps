여러 마커에 클릭 핸들러를 달아, 클릭한 마커의 정보 창을 여닫는 예제입니다.

<Example of={MarkerViewporteventsExample} />

## 설명

영역 필터는 [보이는 지도 영역의 마커만 표시하기](/react-naver-maps/examples/marker-viewport/) 와 같습니다. 마커 `ref` 는 `setMarker` 로 state 에 담아 `InfoWindow` 의 `anchor` 로 넘깁니다. 다른 정보 창이 열려 SDK 가 이 창을 닫으면 `onClose` 로 state 를 맞춥니다.
