## 설명

`InfoWindow`의 `content`에 HTML 문자열을, `anchor`에 `Marker` 인스턴스를 전달합니다. `Marker`의 `ref`를 state에 담으면(`ref={setMarker}`) 인스턴스가 만들어진 뒤 `anchor`로 사용할 수 있습니다. 열림 여부는 `open` state로 관리합니다. SDK가 다른 정보 창을 열면서 이 창을 닫을 때는 `onClose`로 state를 갱신합니다.
