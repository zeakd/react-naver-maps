층별 실내 지도를 `ImageMapType`으로 만들고 지도 유형 컨트롤로 층을 고릅니다.

<Example of={MapTypesTutorial8GreenFactoryExample} />

## 설명

층마다 `ImageMapType`을 만들어 `MapTypeRegistry`(`+1F`, `+2F`, `+4F`, `+5F`)에 넣습니다. 컨트롤은 `mapTypeControlOptions`의 `mapTypeIds`, `position`, `style`로 정합니다. 투영법은 평면 좌표를 타일 크기로 나눠 타일 좌표로 씁니다.
