## 설명

`DrawingManager`를 `NaverMap`의 자식으로 둡니다(`submodules={['drawing']}`). 이미 올린 `Rectangle`, `Polygon`은 `ref`로 받아 매니저 ref의 `addDrawing`에 등록합니다.

이벤트 기록은 그룹 이벤트(`DrawingEvents.ADD`, `SELECT`, `REMOVE`)도 도형 종류별 이벤트와 함께 매니저의 `addListener`로 듣고, effect 정리에서 `Event.removeListener`로 뗍니다. 그룹 이벤트만 필요하면 `onDrawingAdded`, `onDrawingSelected`, `onDrawingRemoved` prop을 쓸 수 있습니다.
