## 설명

`DrawingManager` 를 `NaverMap` 의 자식으로 둡니다(`submodules={['drawing']}`). 이미 올린 `Rectangle`, `Polygon` 은 `ref` 로 받아 매니저 ref 의 `addDrawing` 에 등록합니다.

그룹 이벤트는 `onDrawingAdded`, `onDrawingSelected`, `onDrawingRemoved` prop 이 있습니다. 도형 종류별 이벤트(`rectangleAdded` 등)는 prop 이 없어 매니저의 `addListener` 로 듣습니다.

한계: 선언적으로 둔 도형을 그리기 도구에 등록하는 prop 이 없어 `addDrawing` 을 effect 에서 부릅니다.
