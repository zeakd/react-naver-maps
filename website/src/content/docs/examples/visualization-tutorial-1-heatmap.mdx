## 설명

`react-naver-maps/visualization` 의 `HeatMap` 에 `[경도, 위도]` 배열을 `data` 로 넘깁니다(`submodules={['visualization']}`). 지도가 준비된 뒤에 붙으므로 `init` 을 직접 기다리지 않아도 됩니다.
