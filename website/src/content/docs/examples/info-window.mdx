마커를 누르면 정보 창이 열리고 닫힙니다. 열림 여부는 state로 관리합니다.

<Example of={InfoWindowExample} />

## 설명

`InfoWindow`의 `open` prop이 열림 여부입니다. 마커의 `onClick`이 state를 뒤집고, 정보 창이 닫히면 오는 `onClose`로 state를 맞춥니다. `content` 에는 문자열이나 HTML 요소를 줍니다.

마커 여러 개 중 하나의 정보 창만 열려면 열린 마커의 id 를 state로 두고 `<InfoWindow open anchor>` 하나를 그립니다([오버레이의 이벤트](/react-naver-maps/examples/event-tutorial-3-overlay/)).
