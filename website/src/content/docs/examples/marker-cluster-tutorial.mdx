<Example of={MarkerClusterExample} />

## 설명

`NaverMap` 의 자식 컴포넌트에서 `useMap()` 으로 지도 인스턴스를 받아 `useEffect` 안에서 `navermaps.Marker` 와 `MarkerClustering` 을 직접 생성합니다. 서드파티 유틸리티 등을 사용할 때 이와 같이 SDK 객체에 직접 접근할 수 있습니다.
