<Example of={MarkerClusterExample} />

## 설명

마커와 클러스터는 컴포넌트로 그리지 않고, `NaverMap` 의 자식 컴포넌트가 `useMap()` 으로 지도 인스턴스를 받아 `useEffect` 안에서 `navermaps.Marker` 와 `MarkerClustering` 을 직접 만듭니다. 컴포넌트로 감싸지 않는 imperative 사용은 서드파티 유틸이나 고급 사용 시에 활용할 수 있습니다.
