## 설명

`new navermaps.ImageMapType({ tileSet, projection, ... })` 로 만든 지도 유형을 `MapTypeRegistry` 에 `osm` 으로 등록하고 `NaverMap` 의 `mapTypes` 에 줍니다. 공식 예제의 `map.mapTypes.set('osm', ...)` 와 `setMapTypeId('osm')` 은 이 레지스트리와 `defaultMapTypeId="osm"` 가 됩니다.

`mapTypes` 를 주면 기본 지도 유형을 대신하므로, 일반, 지형도, 위성, 겹쳐보기를 함께 쓰려고 네 가지를 같이 넣습니다(예제의 `defaultMapTypes`). 레지스트리는 `useMemo` 로 한 번만 만듭니다.

출처 표기(`provider`)는 이미지 제공처의 정책을 따라야 합니다.
