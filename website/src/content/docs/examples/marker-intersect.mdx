겹친 마커에 마우스를 올리면 개수를 표시하고, 클릭하면 목록에서 마커를 선택합니다.

<Example of={MarkerIntersectExample} />

## 설명

이벤트가 발생하면 `NaverMap` `ref`의 `getProjection().fromCoordToOffset()`으로 화면 픽셀 거리를 계산해 겹침을 판정합니다. 목록을 연 마커는 `cover` state로 관리하여 마우스가 벗어나도 강조를 유지합니다. 지도를 누르거나 움직이면(`onClick`·`onIdle`) 안내와 목록을 닫습니다.
