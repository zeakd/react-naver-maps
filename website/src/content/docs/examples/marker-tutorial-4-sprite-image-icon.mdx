## 설명

스프라이트 이미지는 `icon.origin` 으로 자를 칸을 고릅니다. `spriteIcon(i, hover)` 가 칸 번호와 마우스 올림 여부로 `icon` 을 만들고, 마우스를 올린 마커는 아래 줄의 over 이미지를 씁니다.
