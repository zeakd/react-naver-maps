브라우저 Geolocation API로 현재 위치를 감지하여 지도에 표시하는 예제입니다.

<Example of={MapGeolocationExample} />

## 설명

`navigator.geolocation.getCurrentPosition()` 으로 현재 위치를 가져온 뒤 `ref` 로 받은 지도의 `setCenter()` 를 호출합니다. 실패하면 지도의 현재 중심에 실패 내용을 표시합니다. `InfoWindow` 의 `content` 는 HTML 문자열입니다.
