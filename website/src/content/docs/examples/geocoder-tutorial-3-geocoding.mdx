## 설명

`geocode`, `reverseGeocode` 는 첫 인자로 `useNavermaps()` 의 값을 받고, 상태가 OK 가 아니면 `GeocoderError` 로 reject 합니다. 처음 한 번은 `useEffect` 에서 `정자동 178-1` 을 검색합니다.

이 서비스는 NCP 콘솔의 Application 에서 Geocoding(Reverse Geocoding) 을 선택해야 응답합니다. 선택하지 않은 키에서는 검색이 실패하고 화면에 오류 문구가 나옵니다.
