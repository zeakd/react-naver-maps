## 설명

`<BicycleLayer />` 를 렌더하면 레이어가 켜지고, 언마운트하면 꺼집니다. SDK 의 `new BicycleLayer()` 와 `setMap(map)`, `setMap(null)` 이 마운트 수명으로 바뀝니다.

켜짐 여부는 React state(`bicycle`)가 갖습니다. 공식 예제가 `bicycleLayer_changed` 이벤트로 버튼 모양을 맞추던 부분은 state 를 그대로 쓰면 되어 필요 없습니다.

지도 유형 컨트롤은 `mapTypeControl` 과 `mapTypeControlOptions` 로 정합니다. 스타일 상수는 `useNavermaps()` 가 주는 `navermaps.MapTypeControlStyle` 에서 받습니다.
