## 설명

길이와 면적은 SDK의 `getDistance()`/`getAreaSize()`로 계산합니다. 이를 위해 클릭 처리 안에서 지도에 표시하지 않는 도형 인스턴스를 잠시 만듭니다. 거리를 잴 때는 점을 찍을 때마다 직전 점부터의 거리를, 완료할 때 전체 거리를 이정표로 표시합니다.
