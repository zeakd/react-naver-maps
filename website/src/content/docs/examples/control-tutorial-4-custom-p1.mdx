지도 컨트롤에 직접 만든 버튼을 넣습니다. 버튼을 누르면 NAVER 그린팩토리로 이동합니다. 컨트롤 두 개를 `TOP_LEFT`와 `LEFT_CENTER`에 둡니다.

<Example of={CustomControlExample} />

## 설명

`CustomControl`의 children이 컨트롤 위치(`position`)에 렌더링됩니다. 일반 React 요소이므로 `onClick`을 그대로 사용할 수 있습니다. 버튼에서는 `useMap()`으로 받은 지도의 `setCenter()`를 호출합니다.

지도가 준비(`init`)되기 전에 마운트해도 준비된 뒤 붙습니다. SDK의 `CustomControl.setMap`은 준비 전에는 붙이지 않기 때문입니다.
