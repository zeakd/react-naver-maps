## 설명

`CustomControl` 의 children 이 컨트롤 자리(`position`)에 그려집니다. 공식 예제의 `new CustomControl(html, { position })` 과 `map.controls[position].push(element)` 두 방식이 모두 `CustomControl` 하나로 됩니다. 일반 React 요소라 `onClick` 을 그대로 씁니다. 버튼은 `useMap()` 으로 받은 지도에 `setCenter()` 를 부릅니다.

지도가 준비(`init`)되기 전에 마운트해도 준비된 뒤 붙습니다. SDK 의 `CustomControl.setMap` 은 준비 전에는 붙이지 않기 때문입니다.
