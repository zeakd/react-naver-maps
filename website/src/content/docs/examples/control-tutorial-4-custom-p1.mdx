지도의 컨트롤 자리에 직접 만든 버튼을 넣고, 누르면 NAVER 그린팩토리로 이동하는 예제입니다. 컨트롤 두 개를 `TOP_LEFT` 와 `LEFT_CENTER` 에 둡니다.

<Example of={CustomControlExample} />

## 설명

`CustomControl` 의 children 이 컨트롤 자리(`position`)에 그려집니다. 일반 React 요소라 `onClick` 을 그대로 씁니다. 버튼은 `useMap()` 으로 받은 지도에 `setCenter()` 를 부릅니다.

지도가 준비(`init`)되기 전에 마운트해도 준비된 뒤 붙습니다. SDK 의 `CustomControl.setMap` 은 준비 전에는 붙이지 않기 때문입니다.
