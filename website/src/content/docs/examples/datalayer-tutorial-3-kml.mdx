## 설명

`Kml`의 `data`는 문자열이 아니라 XML `Document`입니다. 받은 텍스트를 `DOMParser`로 한 번만 파싱해(`useXml`) 같은 참조를 넘깁니다. 참조가 바뀌면 이전 feature를 빼고 다시 올립니다.
