## 설명

`icon` 에 `{ content, size, anchor }` 를 주면 HTML 아이콘입니다. `draggable` 과 `title` 은 일반 prop 이고, 드래그로 바뀐 위치를 라이브러리가 되돌리지 않도록 처음 위치만 `defaultPosition` 으로 줍니다. 한계: 공식 예제는 문서 사이트의 CSS 클래스(`cs_mapbridge`)로 스프라이트를 자르는데, 여기서는 같은 스타일을 인라인으로 풀어 썼습니다.
