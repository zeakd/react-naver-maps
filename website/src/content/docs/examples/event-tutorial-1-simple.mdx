## 설명

지도 이벤트 prop의 인자는 SDK의 `PointerEvent`(`coord`, `point`, `offset`)이고, `onKeydown`은 `{ keyboardEvent }`를 받습니다. 마커 목록과 정보 창은 React state로 그립니다.

`keydown` 이벤트는 지도에 초점이 있을 때 발생합니다. 지도를 한 번 클릭해 초점을 맞출 수 있습니다.
