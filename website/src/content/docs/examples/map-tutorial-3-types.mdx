## 설명

`NaverMap` 의 `mapTypeId` prop 에 state 를 주어 `'normal'`, `'terrain'`, `'satellite'`, `'hybrid'` 사이를 전환합니다. `navermaps.MapTypeId` 의 `NORMAL`, `TERRAIN`, `SATELLITE`, `HYBRID` 와 같은 값입니다.
