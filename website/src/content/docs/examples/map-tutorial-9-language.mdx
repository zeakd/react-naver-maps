## 설명

스크립트를 불러올 때 정하는 언어는 `NavermapsProvider` 의 `language="en"` 입니다(`ko` 기본, `en`, `zh`, `ja`). 한 페이지에서는 처음 불러온 언어가 쓰입니다.

지도 글자의 언어는 지도 유형의 `overlayType` 입니다. 공식 예제처럼 `getNormalMap({ overlayType })` 를 `mapTypes` 의 `normal` 로 등록합니다.

> [네이버 공식 튜토리얼 - 언어 설정하기](https://navermaps.github.io/maps.js.ncp/docs/tutorial-9-map-language.example.html)
