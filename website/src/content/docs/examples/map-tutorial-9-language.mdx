## 설명

스크립트를 불러올 때 `NavermapsProvider`의 `language`로 언어를 설정합니다(`ko` 기본, `en`, `zh`, `ja`). 한 페이지에서는 처음 불러온 언어가 사용됩니다.

지도 글자의 언어는 지도 유형의 `overlayType`입니다. `getNormalMap({ overlayType })`을 `mapTypes`의 `normal`로 등록합니다.
