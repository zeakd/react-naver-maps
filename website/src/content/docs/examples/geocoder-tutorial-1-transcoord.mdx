## 설명

`TransCoord`는 geocoder 서브모듈이 주는 함수 모음이라 `useNavermaps()`로 받은 `navermaps.TransCoord`를 그대로 씁니다. 클릭 좌표는 `onClick`의 `e.coord`입니다.
