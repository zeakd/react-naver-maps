## 설명

`TransCoord` 는 geocoder 서브모듈이 주는 함수 모음이라 `useNavermaps()` 로 받은 `navermaps.TransCoord` 를 그대로 씁니다(`submodules={['geocoder']}`). 클릭 좌표는 `onClick` 의 `e.coord` 이고(`LatLng` 로 단언), 결과는 state 에 두고 `InfoWindow` 의 `content` 로 보입니다. 공식 예제는 값을 콘솔에만 찍고 정보 창에는 설명 문구를 넣는데, 여기서는 변환된 값을 보입니다.
