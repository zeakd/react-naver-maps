<Example of={DrawingTutorial3RestoreExample} />

## 설명

매니저의 `ref` 로 받은 인스턴스의 `toGeoJson()` 으로 그린 도형을 뽑아 state 에 둡니다. 오른쪽 지도는 그 값을 `GeoJson`(`autoStyle`)의 `data` 로 받습니다. 새로 뽑으면 `GeoJson` 이 이전 것을 빼고 다시 올립니다.
