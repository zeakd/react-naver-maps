## 설명

`NaverMap` 의 `maxBounds`, `minZoom` prop 을 사용합니다. 초기 줌은 16 입니다. `minZoom` 과 같은 14 에서 시작하면 더 축소할 수 없어 줌아웃이 되돌아갑니다.
