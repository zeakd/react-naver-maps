## 설명

`maxBounds`, `minZoom` 이 `NaverMap` prop 입니다. 경계는 `{ south, west, north, east }` 리터럴이라 `Marker`, `Rectangle` 에도 그대로 씁니다.

줌 레벨은 `onZoomChanged` 로 받아 state 에 둡니다. 공식 예제는 중심을 정하지 않는데 여기서는 독도 가운데로 지정했습니다. 처음 줌은 공식 예제와 같은 16 입니다. `minZoom` 과 같은 14 에서 시작하면 더 줄일 수 없어 줌아웃이 튕기기만 합니다.
