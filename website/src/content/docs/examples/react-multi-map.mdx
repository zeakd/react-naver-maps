지도 두 개를 나란히 두고, 한쪽을 움직이면 다른 쪽이 따라오게 합니다. 오른쪽은 위성 지도로 3단계 넓게 봅니다.

<Example of={MultiMapExample} />

## 설명

`NavermapsProvider` 하나 아래에 `Container` 와 `NaverMap` 을 여러 번 두면 지도마다 따로 동작합니다. SDK 스크립트는 한 번만 불러옵니다.

따라가게 할 때는 두 지도가 서로를 끝없이 움직이지 않게 합니다. 이 예제는 사용자가 지금 만지는 지도(`leader`)만 다른 지도를 움직입니다. 따라오는 지도의 `center_changed` 는 `leader` 가 아니라서 되돌려 보내지 않습니다.
