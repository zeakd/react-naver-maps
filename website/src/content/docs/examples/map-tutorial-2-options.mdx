## 설명

`NaverMap`의 `draggable`, `scrollWheel`, `disableDoubleClickZoom`, `disableKineticPan`, `keyboardShortcuts`, `tileTransition`, `minZoom`, `maxZoom`, 컨트롤 표시 props(`zoomControl`, `scaleControl`, `mapTypeControl` 등)를 controlled로 사용하여 런타임에 옵션을 토글할 수 있습니다. `logoControl` 은 `false` 로 끌 수 없습니다(SDK 가 거부합니다).
