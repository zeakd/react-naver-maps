## 설명

`NaverMap` 의 `draggable`, `pinchZoom`, `scrollWheel`, `keyboardShortcuts`, `disableDoubleTapZoom`, `disableDoubleClickZoom`, `disableTwoFingerTapZoom`, `disableKineticPan`, `tileTransition`, `minZoom`, `maxZoom`, 컨트롤 표시 prop(`zoomControl`, `scaleControl`, `mapTypeControl` 등)에 state 를 주어 실행 중에 옵션을 바꿉니다. `logoControl` 은 `false` 로 끌 수 없습니다(SDK 가 거부합니다).
