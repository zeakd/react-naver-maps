## 설명

SVG `<pattern>` 을 문서에 두고 도형의 `fillColor` 에 `url(#id)` 를 줍니다. 마우스를 올리거나 벗어날 때 무늬를 바꾸는 부분은 `getElement().style.fill` 대신 도형별 무늬 state 입니다. 한계: 공식 예제의 무늬 20종은 쓰지 않고 간단한 무늬 5종을 직접 그렸습니다.
