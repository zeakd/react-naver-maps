## 설명

17개 파일을 `Promise.all` 로 받아 한 FeatureCollection 으로 합쳐 `GeoJson` 하나에 넘깁니다(합친 값은 `useMemo`). 선택 상태는 `feature.setProperty('focus', ...)` 로 두고 `style` 함수가 읽습니다. 이름표는 지도 위에 놓은 일반 `div` 이고, 위치는 이벤트의 `e.offset` 입니다.

경계선 색 버튼은 `style` 에 넘기는 함수를 바꿉니다. 색마다 함수를 컴포넌트 밖에 하나씩 두어, 버튼을 누를 때만 이 `GeoJson` 의 feature 를 다시 칠합니다.
