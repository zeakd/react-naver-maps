## 설명

17개 파일을 `Promise.all` 로 받아 한 FeatureCollection 으로 합쳐 `GeoJson` 하나에 넘깁니다(합친 값은 `useMemo`). 선택 상태는 `feature.setProperty('focus', ...)` 로 두고 `style` 함수가 읽습니다. 공식 예제가 `floatPane` 에 붙이는 이름표는 지도 위에 놓은 일반 `div` 이고, 위치는 이벤트의 `e.offset` 입니다.
