타일마다 `(z, x, y)` 를 적은 격자 레이어를 지도에 얹어 타일 그리드를 살펴보는 예제입니다.

<Example of={MapTypesTutorial1TileCheckExample} />

## 설명

`<Layer>` 의 `mapTypes` 에는 `getTile` 이 DOM 요소를 돌려주는 사용자 지도 유형을 줍니다.

`mapTypes` 는 `useMemo` 로 한 번만 만듭니다. 렌더마다 새 `getTile` 함수를 가진 객체를 주면 레이어가 렌더마다 다시 만들어집니다. 자세한 내용은 [Layer](/react-naver-maps/api-references/layer/) 를 보세요.
