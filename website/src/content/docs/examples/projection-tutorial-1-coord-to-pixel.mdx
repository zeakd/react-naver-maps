## 설명

`ref` 로 받은 지도의 `getProjection()` 을 호출하고 `fromCoordToOffset()`, `fromOffsetToCoord()` 로 좌표와 픽셀을 변환합니다. 경계는 React state(`bounds`)로 관리하고 `Rectangle` 과 두 `Marker` 에 전달합니다.

처음 경계는 지도 `init` 뒤에 읽을 수 있어 `onInit` 에서 `getBounds()` 로 채웁니다.

`getBounds()`, `fromOffsetToCoord()` 의 반환값은 `LatLngBounds`, `LatLng` 로 타입을 단언합니다. `@types` 에서는 상위 타입으로 선언되어 있습니다.
