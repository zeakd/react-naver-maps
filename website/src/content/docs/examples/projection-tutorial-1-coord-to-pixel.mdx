<Example of={ProjectionTutorial1CoordToPixelExample} />

## 설명

`ref` 로 받은 지도에 `getProjection()` 을 부르고 `fromCoordToOffset()`, `fromOffsetToCoord()` 로 좌표와 픽셀을 오갑니다. 경계는 React state(`bounds`)이고 `Rectangle` 과 두 `Marker` 에 그대로 넘깁니다.

처음 경계는 지도 `init` 뒤에 읽을 수 있어 `onInit` 에서 `getBounds()` 로 채웁니다.

타입: `getBounds()`, `fromOffsetToCoord()` 가 돌려주는 값은 `LatLngBounds`, `LatLng` 로 단언합니다(`@types` 가 상위 타입으로 적어 둡니다).
