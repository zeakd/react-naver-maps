## 설명

`Panorama` 의 자식으로 `Marker` 를 두면 거리뷰 위에 그립니다. `onInit` 에서 `getProjection().fromCoordToPov()` 로 마커 방향의 `pov` 를 구해 state 로 넘깁니다. 마커 추가·제거 버튼은 마운트로 합니다(`{showMarker && <Marker />}`).
