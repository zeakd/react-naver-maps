## 설명

`Marker` 의 `animation` 은 값이 바뀔 때만 적용됩니다. SDK 는 `DROP` 이 끝나면 값을 `null` 로 돌리지만 다시 렌더해도 다시 떨어지지 않습니다. 그래서 지금 상태는 state 가 아니라 `ref` 의 `getAnimation()` 으로 읽습니다. `icon` 은 이미지 URL·SymbolIcon·HtmlIcon, `shape` 는 SymbolIcon 의 클릭 영역입니다.
