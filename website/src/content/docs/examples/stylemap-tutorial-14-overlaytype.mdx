일반 지도 배경에 실시간 혼잡 교통 정보를 얹는 `overlayType` 을 지정하는 예제입니다.

<Example of={StyleMapTutorial14OverlayTypeExample} />

## 설명

`NaverMap` 의 `mapTypes` 에 `MapTypeRegistry` 를 주고, `NaverStyleMapTypeOptions.getNormalMap({ overlayType })` 로 만든 지도 유형을 `normal` 로 등록합니다.

레지스트리는 `useMemo` 로 한 번만 만듭니다. 렌더마다 새로 만들면 지도 유형이 매번 바뀝니다.
