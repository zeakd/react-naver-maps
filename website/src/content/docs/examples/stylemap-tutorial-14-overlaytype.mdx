## 설명

`NaverStyleMapTypeOptions.getNormalMap({ overlayType })` 로 만든 지도 유형을 `normal` 로 등록합니다. 렌더마다 레지스트리를 새로 만들면 지도 유형이 매번 바뀌므로 `useMemo` 로 한 번만 만듭니다.
