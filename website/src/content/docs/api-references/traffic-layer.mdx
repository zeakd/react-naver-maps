`TrafficLayer`는 실시간 교통 레이어를 지도 위에 표시합니다.

## 사용법

```tsx
import { TrafficLayer } from 'react-naver-maps';

<NaverMap>
  <TrafficLayer />
</NaverMap>;
```

## 자동 갱신

`autoRefresh`를 설정하면 교통 정보를 주기적으로 자동 갱신합니다. `false` 로 두면 끕니다. SDK 는 레이어를 지도에 붙일 때마다(숨겼다 다시 보일 때 포함) 교통 정보 버전을 받은 뒤 자동 갱신을 다시 켜서, 라이브러리가 붙인 뒤 5초까지 몇 번 다시 끕니다. 네트워크가 그보다 느리면 켜진 채 남을 수 있으니 그때는 `ref` 로 `endAutoRefresh()` 를 부릅니다.

```tsx
<TrafficLayer autoRefresh interval={60000} />
```
