`NavermapsProvider`는 네이버 지도 스크립트 로딩에 필요한 인증 정보를 하위 컴포넌트에 제공합니다. 앱 최상위에 배치해 주세요.

## 사용법

```tsx
import { NavermapsProvider } from 'react-naver-maps';

function App() {
  return (
    <NavermapsProvider ncpKeyId="YOUR_NCP_KEY_ID">
      <MyMap />
    </NavermapsProvider>
  );
}
```

## 인증 키

NCP 콘솔 [Maps > Application](https://console.ncloud.com/maps/application)에서 발급한 Client ID를 `ncpKeyId`로 전달해 주세요.
Application의 Web 서비스 URL에 지도를 띄울 주소(로컬 개발 주소 포함)를 등록해야 인증됩니다.

AI NAVER API의 지도 API는 2026-11-24 18:00부터 쓸 수 없습니다([네이버 클라우드 공지](https://www.ncloud.com/support/notice/all/2200)). 그래서 0.3.0에서 `ncpClientId`·`govClientId`·`finClientId`를 제거했습니다. 기존 키는 Maps로 옮겨지지 않으므로 Maps에서 Application을 새로 등록해야 합니다. ([#174](https://github.com/zeakd/react-naver-maps/issues/174))

## 서브모듈

네이버맵 서브모듈(예: drawing, visualization)을 로드하려면 `submodules`를 전달합니다.

```tsx
<NavermapsProvider
  ncpKeyId="YOUR_NCP_KEY_ID"
  submodules={['drawing', 'visualization']}
>
  ...
</NavermapsProvider>
```

GL(`gl`)은 다른 서브모듈과 함께 쓰지 않습니다(공식 문서 "GL 생성 및 기본 동작").

## 언어

지도 글자와 컨트롤의 언어를 `language`로 정합니다. SDK가 받는 값은 `ko`(기본), `en`, `zh`, `ja` 입니다.

```tsx
<NavermapsProvider ncpKeyId="YOUR_NCP_KEY_ID" language="en">
  ...
</NavermapsProvider>
```

SDK는 한 페이지에서 한 번만 불러오므로, 처음 불러온 언어가 그 페이지의 언어입니다.

## 인증 실패

키가 틀렸거나, Web 서비스 URL 이 등록되지 않았거나, Application 에서 Dynamic Map 을 선택하지 않았으면 SDK가 인증에 실패합니다. 지도는 그려지지 않고 SDK는 곧 `naver.maps`를 비웁니다. `onAuthFailure`로 알아챌 수 있습니다.

```tsx
<NavermapsProvider
  ncpKeyId="YOUR_NCP_KEY_ID"
  onAuthFailure={() => setAuthFailed(true)}
>
  ...
</NavermapsProvider>
```

SDK는 전역 `window.navermap_authFailure`를 부릅니다. 페이지가 먼저 둔 이 함수도 함께 불립니다.

## TypeScript

SDK 타입은 [`@types/navermaps`](https://www.npmjs.com/package/@types/navermaps) 를 씁니다. TypeScript 에서는 함께 설치합니다.

```sh
npm i -D @types/navermaps
```
