`CustomControl`은 React children을 지도 컨트롤 위치에 그립니다. SDK의 `naver.maps.CustomControl`을 사용합니다.

## 사용법

```tsx
import { CustomControl, useMap } from 'react-naver-maps';

function HomeControl() {
  const map = useMap();
  return (
    <CustomControl position="TOP_RIGHT">
      <button onClick={() => map.setCenter({ lat: 37.5, lng: 127.0 })}>
        처음 위치
      </button>
    </CustomControl>
  );
}
```

`position`에는 이름(`'TOP_RIGHT'`)이나 SDK 상수(`navermaps.Position.TOP_RIGHT`)를 넘깁니다. 값을 바꾸면 해당 위치로 옮깁니다. 지도가 준비(`init`)되기 전에 마운트해도 준비된 뒤 표시됩니다.
