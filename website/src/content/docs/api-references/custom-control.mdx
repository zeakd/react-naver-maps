`CustomControl` 컴포넌트는 React children 을 지도의 컨트롤 자리에 그립니다. SDK 의 `naver.maps.CustomControl` 입니다.

## 사용법

```tsx
import { CustomControl, useMap } from 'react-naver-maps';

function HomeControl() {
  const map = useMap();
  return (
    <CustomControl position="TOP_RIGHT">
      <button onClick={() => map.setCenter({ lat: 37.5, lng: 127.0 })}>
        처음 위치
      </button>
    </CustomControl>
  );
}
```

`position` 은 이름(`'TOP_RIGHT'`)이나 SDK 상수(`navermaps.Position.TOP_RIGHT`)입니다. 바꾸면 그 자리로 옮깁니다. 지도가 준비(`init`)되기 전에 마운트해도 준비된 뒤 붙습니다.
