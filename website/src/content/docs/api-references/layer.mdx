`Layer`는 사용자 정의 레이어를 지도 위에 표시합니다. SDK의 `new naver.maps.Layer(name, mapTypes, options)`를 사용합니다.

## 사용법

타일마다 좌표를 보여 주는 격자 레이어(공식 예제 `tutorial-1-maptypes-tilecheck`) 입니다.

```tsx
import { useMemo } from 'react';
import { Layer, NaverMap, useNavermaps } from 'react-naver-maps';

function Map() {
  const navermaps = useNavermaps();
  const tileGrid = useMemo(
    () => ({
      name: 'TileGrid',
      minZoom: -1,
      maxZoom: 14,
      tileSize: new navermaps.Size(256, 256),
      getTile: (x: number, y: number, z: number) => {
        const div = document.createElement('div');
        div.textContent = `(${z}, ${x}, ${y})`;
        return div;
      },
    }),
    [navermaps],
  );

  return (
    <NaverMap>
      <Layer name="tileGrid" mapTypes={tileGrid} />
    </NaverMap>
  );
}
```

- `mapTypes`는 MapTypeRegistry 이거나 MapType 객체 하나입니다. 문서의 인자 이름은 `MapTypeRegistry`, SDK 코드의 이름은 `mapTypes` 입니다. MapType 하나를 주면 SDK가 `name`을 키로 레지스트리를 만듭니다.
- `name`, `mapTypes`, `hd`, `overlayMap`, `zIndex`는 SDK에 setter 가 없어 바뀌면 레이어를 떼고 다시 만듭니다(값으로 비교).
- `mapTypes`는 `useMemo`로 한 번만 만들어 주세요. 렌더마다 새 객체를 만들면(`getTile`이 매번 새 함수이면) 레이어가 다시 만들어집니다.
- `name`은 지도의 `map.layers` 키이자 `map.<name>Layer` 키라서 지도 안에서 다른 레이어와 겹치지 않게 씁니다(`bicycle`, `label` 등은 내장 레이어 이름).
- 불투명도 등 나머지는 `ref`로 `setOpacity` 같은 SDK 메서드를 부릅니다. 켜고 끄는 것은 `ref.setMap`이 아니라 마운트로 합니다.
- 문서는 `LayerOptions`를 곧 제거될 옵션이라 적습니다(기본 지도 타일에 합치는 방식으로 바뀜). `hd`는 3.10.5 코드에서 읽는 곳을 찾지 못했습니다.
