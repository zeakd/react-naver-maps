`react-naver-maps/visualization`은 SDK의 visualization 서브모듈(`naver.maps.visualization`)에 있는 `HeatMap`, `DotMap`을 컴포넌트로 제공합니다.

```tsx
<NavermapsProvider ncpKeyId="..." submodules={['visualization']}>
```

## 사용법

```tsx
import { HeatMap, DotMap } from 'react-naver-maps/visualization';

<NaverMap>
  <HeatMap data={points} radius={20} opacity={0.6} />
  <DotMap data={stores} fillColor="#03c75a" />
</NaverMap>;
```

- `data`는 `LatLng`, `[경도, 위도]`, `WeightedLocation`의 배열입니다. 값으로 비교해 바뀌면 다시 그립니다.
- 지도가 준비(`init`)된 뒤에 붙입니다. SDK는 준비 전에 붙인 HeatMap을 그리지 않습니다.
- 서브모듈을 불러오지 않고 쓰면 불러오는 법을 담은 에러를 던집니다.
