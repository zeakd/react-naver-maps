`GeoJson` 컴포넌트는 GeoJSON 을 지도의 데이터 레이어(`map.data`)에 올립니다. SDK 의 `naver.maps.Data.addGeoJson` 입니다.

## 사용법

```tsx
import { GeoJson } from 'react-naver-maps';

<NaverMap>
  <GeoJson
    data={regions}
    style={(feature) => ({ fillColor: feature.getProperty('color') })}
    onClick={(e) => select(e.feature.getProperty('id'))}
  />
</NaverMap>;
```

- `style` 은 객체나 feature 를 받는 함수입니다. 이 컴포넌트가 올린 feature 에만 적용됩니다.
- 이벤트(`onClick` 등)는 이 컴포넌트가 올린 feature 에서 난 것만 받습니다. 어느 feature 인지는 `e.feature` 로 압니다.
- `autoStyle` 을 켜면 GeoJSON `properties` 의 스타일 값을 씁니다.
- `data` 가 값으로 바뀌면 이전 feature 를 빼고 새로 올립니다. GeoJSON 에 `bbox` 가 있으면 SDK 가 그 영역으로 지도를 맞춥니다.

지도마다 데이터 레이어는 하나라서 `style` 을 컴포넌트마다 나누려고 `map.data.setStyle` 은 라이브러리가 씁니다. `GeoJson` 과 함께 `map.data.setStyle` 을 직접 부르면 덮어씁니다.
