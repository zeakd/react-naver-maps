`NaverMap` 컴포넌트는 네이버 지도를 렌더링합니다. `Container` 컴포넌트 내부에서 사용해야 합니다.

## 사용법

```tsx
import { Container as MapDiv, NaverMap } from 'react-naver-maps';

<MapDiv style={{ width: '100%', height: '400px' }}>
  <NaverMap
    defaultCenter={{ lat: 37.3595704, lng: 127.105399 }}
    defaultZoom={15}
  />
</MapDiv>;
```

## Controlled vs Uncontrolled

`NaverMap`은 `center`/`defaultCenter`, `zoom`/`defaultZoom` 등 controlled/uncontrolled 패턴을 지원합니다.

- `defaultCenter`: 초기 중심 좌표 (uncontrolled)
- `center`: 중심 좌표 (controlled, 외부에서 값을 관리)

카메라 값(`center`, `zoom`)은 props가 바뀔 때만 지도에 적용합니다. 드래그나 핀치 중과 관성이 멈출 때까지는 적용을 미룹니다. 늦게 돌아온 값과 래스터 지도의 실수 zoom은 [핵심 개념](/react-naver-maps/guides/core-concepts/)의 규칙대로 다룹니다. 그 밖의 controlled prop은 사용자 조작이나 ref 호출로 바뀌면 다음 렌더에서 prop 값으로 되돌립니다.

## 알아 둘 것

- `cursor`: SDK는 드래그 중 커서가 손 모양(`"open"`/`"closed"`)일 때만 둘을 오갑니다. `"crosshair"` 같은 다른 값은 그대로 둡니다.
- `mapTypes`는 `useMemo`로 한 번 만듭니다([지도 유형과 레이어](/react-naver-maps/guides/map-types/)).
- `gl`, `customStyleId`, `useStyleMap`, `repeatX`, `blankTileImage`, `tileDuration`은 생성 때만 적용됩니다. 바꾸면 개발 모드에서 경고합니다. 바꾸려면 `key`로 다시 만듭니다.
- 줌 효과의 시작과 끝은 `onZoomstart`, `onZoomend`, GL의 실수 줌은 `onZoom`입니다. 래스터 지도에서 `zoom` prop만 바꾸면 효과 없이 적용하므로 이 이벤트가 발생하지 않습니다. `center`와 함께 바꾸거나(`morph`) GL 지도에서는 발생합니다.
- 이벤트 이름과 인자는 [이벤트](/react-naver-maps/guides/events/)를 참고해 주세요.
