`Marker` 컴포넌트는 지도 위에 마커를 표시합니다.

## 사용법

```tsx
import { Marker, useNavermaps } from 'react-naver-maps';

const navermaps = useNavermaps();
<Marker position={{ lat: 37.5, lng: 127.0 }} />;
```

## 아이콘

`icon` 은 SDK 의 네 가지 아이콘을 그대로 받습니다. 객체는 렌더마다 새로 만들어도 값이 같으면 다시 넣지 않습니다.

```tsx
<Marker position={p} icon="https://example.com/pin.png" />  {/* 이미지 URL */}
<Marker
  position={p}
  icon={{
    url: '/pin@2x.png',            // ImageIcon. 레티나는 큰 이미지를 scaledSize 로 줄인다
    size: { width: 22, height: 35 },
    scaledSize: { width: 22, height: 35 },
    anchor: { x: 11, y: 35 },
  }}
/>
<Marker position={p} icon={{ path: navermaps.SymbolPath.CIRCLE, radius: 8, fillColor: '#f00' }} />  {/* SymbolIcon */}
<Marker position={p} icon={{ content: '<div class="pin">1</div>', anchor: { x: 12, y: 12 } }} />  {/* HtmlIcon */}
```

이미지 아이콘을 다 불러오면 `onIconLoaded` 가 옵니다. `shape` 로 클릭 영역을 정합니다.

## 애니메이션

`animation` 은 바뀔 때만 적용합니다. DROP 이 끝나면 SDK 가 값을 null 로 바꾸는데, 다시 렌더해도 다시 떨어지지 않습니다. `null` 을 주면 BOUNCE 를 멈춥니다.

```tsx
<Marker position={p} animation={bouncing ? navermaps.Animation.BOUNCE : null} />
```

## 위치 읽기

`position` 을 주면 그 값이 기준입니다. 끌어 놓아도 다시 렌더하면 돌아가므로 `onDragend` 로 상태를 바꿉니다. `defaultPosition` 으로 두고 위치만 읽으려면 `onPositionChanged` 를 씁니다.

```tsx
<Marker
  defaultPosition={p}
  draggable
  onPositionChanged={(pos) => setPos(pos)}
/>
```
