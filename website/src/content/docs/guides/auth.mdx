지도가 회색 바탕에 "네이버 지도 Open API 인증이 실패했습니다" 로 뜨면 키나 등록한 주소의 문제입니다. 이 문서는 키를 만드는 법과 인증이 실패할 때 확인할 것을 모았습니다.

## 키 만들기

1. [네이버 클라우드 콘솔](https://console.ncloud.com)의 [Maps > Application](https://console.ncloud.com/maps/application) 에서 Application 을 등록합니다.
2. API 는 **Dynamic Map** 을 고릅니다. 주소 검색(`react-naver-maps/geocoder`)을 쓰면 **Geocoding**, **Reverse Geocoding** 도 고릅니다.
3. **Web 서비스 URL** 에 지도를 띄울 주소를 모두 등록합니다. 배포 주소뿐 아니라 개발 주소(`http://localhost:5173` 등)도 넣습니다.
4. **인증 정보**의 Client ID 를 `NavermapsProvider` 의 `ncpKeyId` 로 넘깁니다.

```tsx
<NavermapsProvider ncpKeyId="YOUR_NCP_KEY_ID">
  <App />
</NavermapsProvider>
```

Client ID 는 브라우저에 그대로 보이는 값입니다. 다른 사이트가 쓰지 못하게 막는 것은 Web 서비스 URL 입니다. Client Secret 은 지도 표시에 쓰지 않으니 코드에 넣지 않습니다.

## 인증이 실패할 때

| 확인할 것                            | 설명                                                                                                                                                                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 지금 주소가 Web 서비스 URL 에 있는가 | 가장 흔한 원인입니다. 개발 서버, 미리보기 배포, 사내 주소처럼 새 주소에서 열었다면 등록합니다.                                                                                                                                                  |
| 등록한 뒤 조금 기다렸는가            | 콘솔에 주소를 더하고 바로는 실패할 수 있습니다. 몇 분 뒤 다시 엽니다.                                                                                                                                                                           |
| Application 에서 고른 API            | 지도는 Dynamic Map, 주소 검색은 Geocoding 을 골라야 합니다.                                                                                                                                                                                     |
| Maps 상품의 키인가                   | 예전 AI·NAVER API 상품 안의 지도 API 는 2026-11-24 18:00 에 종료됩니다([네이버 클라우드 공지](https://www.ncloud.com/support/notice/all/2200)). 그 키(`ncpClientId`)는 쓸 수 없으니 Maps 상품에서 Application 을 만들어 `ncpKeyId` 로 넘깁니다. |

인증 실패는 지도 영역에 문구로 나오고, `NavermapsProvider` 의 `onAuthFailure` 로도 받을 수 있습니다.

```tsx
<NavermapsProvider ncpKeyId={key} onAuthFailure={() => setAuthFailed(true)}>
```

## 지금 주소가 등록됐는지 확인하기

SDK 의 인증 주소를 직접 열어 현재 주소가 인증을 통과하는지 확인할 수 있습니다. `url` 에는 지도를 표시할 페이지의 주소를 넣습니다. 인증에 성공하면 200, 실패하면 401 응답을 받습니다.

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  "https://oapi.map.naver.com/v3/auth?ncpKeyId=YOUR_NCP_KEY_ID&url=https%3A%2F%2Fexample.com%2F"
```
