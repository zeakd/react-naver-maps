react-naver-maps 는 [네이버 지도 JavaScript API v3](https://navermaps.github.io/maps.js.ncp/)(이하 SDK)를 React 에서 쓰기 위한 라이브러리입니다. 지도와 마커, 정보 창, 도형을 컴포넌트로 그리고, 바뀌는 값은 prop 과 state 로 다룹니다. NAVER 가 만든 것이 아닌 오픈소스입니다.

<Example of={BasicMap} />

```bash
npm install react-naver-maps
```

React 19.0 이상이 필요합니다. 키 발급부터는 [빠른 시작](/react-naver-maps/guides/quickstart/)을, 0.3 에서 올린다면 [0.3에서 0.4로](/react-naver-maps/guides/migration-from-03/)를 보세요.

## 설계

**React 와 만나는 부분만 감쌉니다.** SDK 객체를 만들고, prop 이 바뀌면 SDK 에 넣고, `on*` prop 으로 리스너를 붙이고 떼고, 컴포넌트가 사라지면 정리합니다. 지도를 그리고 움직이는 일은 SDK 가 합니다.

```tsx
<NaverMap defaultCenter={{ lat: 37.5666, lng: 126.9784 }} defaultZoom={15}>
  {places.map((p) => (
    <Marker key={p.id} position={p} onClick={() => setSelected(p.id)} />
  ))}
</NaverMap>
```

**SDK 는 그대로 씁니다.** prop 이름은 SDK 옵션 이름과 같습니다. 지도, 마커, 정보 창, 도형은 컴포넌트가 모르는 옵션도 SDK 에 그대로 넘기므로 SDK 에 새 옵션이 생겨도 라이브러리를 기다리지 않습니다. 컴포넌트가 다루지 않는 일은 `ref` 로 SDK 객체를 받아 직접 부릅니다.

**값으로 비교합니다.** `{ lat, lng }` 같은 객체를 렌더마다 새로 만들어도 값이 같으면 SDK 에 다시 넣지 않습니다. 그래서 `useMemo` 없이 평범하게 써도 됩니다.

**숨겼다 보여도 같은 지도입니다.** `<Activity mode="hidden">` 이나 Suspense 로 잠시 숨기면 지도와 오버레이를 버리지 않고 화면에서만 뗍니다. 다시 보이면 같은 SDK 인스턴스가 돌아옵니다.

자세한 규칙은 [핵심 개념](/react-naver-maps/guides/core-concepts/)에 있습니다.

## 할 수 없는 것

- **SDK 의 동작은 바꾸지 않습니다.** 예를 들어 `maxBounds` 로 영역을 막으면 SDK 는 가장자리에서 미끄러지지 않고 멈춥니다. 라이브러리는 이런 동작을 고치지 않고 그대로 둡니다.
- **브라우저에서만 지도를 그립니다.** 서버 렌더링에서는 `Container` 의 영역만 그리고, 지도는 브라우저에서 SDK 를 불러온 뒤 나타납니다([Next.js 와 SSR](/react-naver-maps/guides/nextjs/)).
- **키는 직접 발급합니다.** 네이버 클라우드 콘솔에서 Maps Application 을 만들고 지도를 띄울 주소를 등록해야 합니다([인증과 키](/react-naver-maps/guides/auth/)).
