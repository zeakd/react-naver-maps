## 사전 준비

네이버맵 API를 사용하려면 NCP(Naver Cloud Platform)에서 클라이언트 ID를 발급받아야 합니다.
[공식 가이드](https://navermaps.github.io/maps.js.ncp/docs/tutorial-1-Getting-Client-ID.html)를 참고하여 발급을 진행해주세요.

1. [Naver Cloud Platform 콘솔](https://console.ncloud.com)에 로그인
2. [Maps > Application](https://console.ncloud.com/maps/application) 에서 Application 등록, API 는 **Dynamic Map** 선택
3. **Web 서비스 URL** 에 지도를 띄울 주소 등록 (로컬 개발 주소 포함, 예: `http://localhost:3000`)
4. 등록 완료 후 **인증 정보**에서 Client ID 확인

## 설치

React 19.0 이상이 필요합니다.

```bash
npm install react-naver-maps
```

TypeScript 를 쓰면 SDK 타입(3.10.0 이상)도 설치합니다.

```bash
npm install -D @types/navermaps
```

## Provider 설정

앱의 루트에 `NavermapsProvider`를 추가합니다. `ncpKeyId`에 발급받은 Client ID를 전달합니다.

```tsx
import { NavermapsProvider } from 'react-naver-maps';

function App() {
  return (
    <NavermapsProvider ncpKeyId="YOUR_NCP_KEY_ID">
      <MyMap />
    </NavermapsProvider>
  );
}
```

## 지도 표시

```tsx
import { Container as MapDiv, NaverMap } from 'react-naver-maps';

function MyMap() {
  return (
    <MapDiv style={{ width: '100%', height: '400px' }}>
      <NaverMap />
    </MapDiv>
  );
}
```

## 마커 추가

```tsx
import { Container as MapDiv, NaverMap, Marker } from 'react-naver-maps';

function MyMap() {
  return (
    <MapDiv style={{ width: '100%', height: '400px' }}>
      <NaverMap
        defaultCenter={{ lat: 37.3595704, lng: 127.105399 }}
        defaultZoom={15}
      >
        <Marker position={{ lat: 37.3595704, lng: 127.105399 }} />
      </NaverMap>
    </MapDiv>
  );
}
```
