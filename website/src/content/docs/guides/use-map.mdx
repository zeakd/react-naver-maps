## useMap()

`useMap()`은 현재 `<NaverMap>` 인스턴스(`naver.maps.Map`)를 반환합니다.
`<NaverMap>` 하위 컴포넌트에서 사용할 수 있습니다.

```tsx
import { useMap } from 'react-naver-maps';

function MyControls() {
  const map = useMap();

  return (
    <div>
      <button onClick={() => map.setZoom(map.getZoom() + 1)}>+</button>
      <button onClick={() => map.setZoom(map.getZoom() - 1)}>-</button>
    </div>
  );
}
```

## 지도 이동

```tsx
function MoveButtons() {
  const map = useMap();
  return (
    <div>
      <button onClick={() => map.panTo({ lat: 37.5666, lng: 126.9784 })}>
        서울시청으로 이동
      </button>
      <button onClick={() => map.morph({ lat: 33.359, lng: 126.5344 }, 12)}>
        제주도로 이동 (줌 포함)
      </button>
    </div>
  );
}
```

`panTo`, `morph`, `setCenter`, `fitBounds`, `panToBounds` 는 좌표·영역을 `{ lat, lng }`, `{ south, west, north, east }` 같은 리터럴로도 받습니다(공식 문서의 `CoordLiteral`, `BoundsLiteral`). SDK 객체를 만들려고 `useNavermaps()` 를 부를 필요가 없습니다.

`panTo`는 애니메이션과 함께 이동합니다. center와 zoom을 동시에 변경할 때는 `morph()`를 사용하세요.
`setCenter()`는 진행 중인 애니메이션을 강제 중단하므로, 일반적인 이동에는 `panTo`가 적합합니다.

`center` prop 을 controlled 로 사용하더라도 메서드로 지도를 이동할 수 있습니다. 지도가 움직이면 `onCenterChanged` 로 앱 상태를 갱신합니다. `center` prop 은 지도가 최근 2초 안에 알려 준 위치를 따르지 않으므로([핵심 개념](/react-naver-maps/guides/core-concepts/)), 지나온 위치로 다시 이동하려면 메서드를 사용합니다.

메서드 인자는 SDK 를 직접 부르는 것이라 SDK 상수를 씁니다. prop 이 받는 상수 이름(`'TOP_RIGHT'`)은 메서드에서는 바뀌지 않습니다.

## 지도 밖에서 쓰기

`useMap()` 은 `<NaverMap>` 아래에서만 씁니다. 지도 밖(옆 목록, 검색창)에서 메서드를 부르려면 `ref` 로 지도를 상태에 받습니다. 지도는 만들어진 뒤에 ref 로 오므로 그전에는 `null` 입니다.

```tsx
function Page() {
  const [map, setMap] = useState<naver.maps.Map | null>(null);
  return (
    <>
      <button
        disabled={!map}
        onClick={() => map?.panTo({ lat: 37.5666, lng: 126.9784 })}
      >
        서울시청
      </button>
      <Container style={{ width: '100%', height: '400px' }}>
        <NaverMap
          ref={setMap}
          defaultCenter={{ lat: 37.3595704, lng: 127.105399 }}
        />
      </Container>
    </>
  );
}
```

`useRef` 를 사용할 수도 있지만 지도가 생성되어도 다시 렌더링하지 않습니다. 지도 생성 여부에 따라 버튼을 켜고 끄려면 위와 같이 state 로 받습니다.

## 현재 상태 조회

```tsx
function MapInfo() {
  const map = useMap();
  const [info, setInfo] = useState('');

  return (
    <div>
      <button
        onClick={() => {
          const center = map.getCenter();
          const zoom = map.getZoom();
          const bounds = map.getBounds();
          setInfo(`center: ${center}, zoom: ${zoom}, bounds: ${bounds}`);
        }}
      >
        현재 상태
      </button>
      {info && <pre>{info}</pre>}
    </div>
  );
}
```

## 컴포넌트 구조

`useMap()`은 `<NaverMap>` 하위에서만 동작합니다. 일반적인 구조:

```tsx
<Container style={{ width: '100%', height: '400px' }}>
  <NaverMap defaultCenter={{ lat: 37.5666, lng: 126.9784 }} defaultZoom={15}>
    <MyControls /> {/* useMap() 사용 가능 */}
    <Marker position={{ lat: 37.5666, lng: 126.9784 }} />
  </NaverMap>
</Container>
```
